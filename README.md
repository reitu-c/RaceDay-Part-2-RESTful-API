# RaceDay Part 2 — RESTful API

A RESTful API for the RaceDay event management system, developed using ASP.NET Core Web API, C#, Entity Framework Core, and SQL Server.

## Features

- User authentication and password hashing
- Session-based authentication and role-based authorisation
- Event and category management
- Enrolment management
- Route management
- Weather record management
- Race result management
- Swagger API documentation
- Unit testing with xUnit

## Technologies

- C#
- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Swagger / OpenAPI
- xUnit

## Project Status

The API builds successfully, and 55 unit tests currently pass locally.
